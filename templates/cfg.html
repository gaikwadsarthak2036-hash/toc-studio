What is a CFG?

Definition & key terms

Definition

A Context-Free Grammar generates strings by repeatedly rewriting nonterminal symbols using its productions, starting from the start symbol.

Leftmost / rightmost derivation

Two conventions for the order in which nonterminals are expanded — always the leftmost one, or always the rightmost one. Both can build the same parse tree.

Parse tree

A tree showing exactly which production was used to expand each nonterminal, with terminal symbols as its leaves.

How this simulator works

It searches (breadth-first) for a sequence of leftmost expansions that produces your target string, within a safety limit — well within reach for the small textbook grammars this tool targets.
