What is a PDA?

Definition & key terms

Definition

A Pushdown Automaton is a finite automaton equipped with a stack, giving it memory an ordinary NFA doesn't have.

Push / pop

Each transition looks at the current state, the next input symbol (or epsilon), and the top of the stack, then moves and replaces that top symbol with zero or more new symbols.

Why a stack?

It lets a PDA recognize languages a DFA/NFA can't, like balanced parentheses or anbn, by "counting" with pushes and pops.

How this simulator works

Because PDAs can be non-deterministic, the simulator searches all possible runs and shows one that accepts (by final state) if one exists.
