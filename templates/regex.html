What is a Regular Expression?

Definition & key terms

Definition

A regular expression is a compact way to describe a set of strings using symbols, alternation, and repetition.

Thompson's Construction

A standard algorithm that turns any regular expression into an equivalent epsilon-NFA, piece by piece, following the expression's structure.

Why not just match directly?

Compiling to an automaton first is exactly how the theory connects regular expressions to finite automata — they describe the same class of languages.

How this simulator works

Your pattern is parsed, compiled into an automaton, and the test string is run against it symbol by symbol, exactly like the other automata modules.
