How it works

  1. 1

    Select a topic

    Choose any module from the dashboard, from Sets all the way to Turing Machines.

  2. 2

    Create your model

    Define states, transitions, grammars or sets using the on-screen builder — no code required.

  3. 3

    Enter input

    Type the string, pair of sets, or expression you want to test.

  4. 4

    Run the simulation

    Step through it one transition at a time, or let it run automatically.

  5. 5

    Visualize the result

    See the diagram, tree, tape or stack update live, ending in a clear Accepted / Rejected verdict.

About the project

Learning Theory of Computation by running it, not just reading it

TOC Studio brings together Discrete Structures and Computational Theory (DSCAT) into one place: sets, relations and functions, finite automata, regular expressions, context-free grammars, pushdown automata, and Turing machines. Instead of tracing transitions on paper, students define their own models and watch them execute, making abstract definitions concrete.

Help & instructions

Getting started

New to a topic?

Open its simulator and read the "What is it?" panel before building your own model.

Not sure what to try first?

Start with the Set Operations module, then build your own relations, functions and automata from scratch in the later modules.

Something looks wrong?

The simulator will explain input errors in plain language instead of a technical error message.
