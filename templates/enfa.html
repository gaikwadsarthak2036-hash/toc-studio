What is an ε-NFA?

Definition & key terms

Definition

An epsilon-NFA is an NFA that can also move between states "for free", without consuming any input symbol.

Epsilon closure

The epsilon closure of a state is every state reachable using only epsilon moves — including the state itself.

Running it

Before and after consuming each symbol, the simulator expands the active states to their full epsilon closure.

Equivalence

Every epsilon-NFA can be converted into a plain NFA (and from there into a DFA) with no change in the language it accepts.
