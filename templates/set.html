What is a Set?

Definition & key terms

Definition

A set is an unordered collection of distinct elements. Writing the same element twice, like {1, 1, 2}, doesn't create a second copy — it's still just {1, 2}.

Union & Intersection

A ∪ B collects every element that appears in A, in B, or in both. A ∩ B keeps only elements that appear in both sets.

Difference

A − B keeps elements of A that are not in B. It isn't symmetric: A − B and B − A are usually different sets.

Power Set

The power set P(A) is the set of all subsets of A, including the empty set and A itself. A set with n elements has exactly 2n subsets.

How this simulator works

Type Set A and Set B as comma-separated elements and press Compute. The backend parses both sets, removes duplicates, runs every operation, and sends the results back to be displayed here — nothing is calculated by guesswork, and every result is a real Python set operation.
