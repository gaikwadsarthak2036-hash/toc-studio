What is a DFA?

Definition & key terms

Definition

A Deterministic Finite Automaton is a finite-state machine where each state has exactly one transition for every input symbol.

Accept / Reject

After the whole input string is consumed, the string is accepted if the machine ends in a final state, otherwise it's rejected.

Determinism

"Deterministic" means there is never a choice: from any state, one symbol leads to exactly one next state.

How this simulator works

Define states, alphabet, transitions, a start state and final states, then press Run. Step through the execution with the controls to see exactly which transition fires at each symbol.
